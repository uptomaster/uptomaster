## 🧑‍💻 About Me

> **기능을 구현하는 것에서 끝나지 않고,**
> 그 기능이 **운영 환경에서 어떻게 동작하고 유지되는지**를 함께 고민하며 프로젝트를 진행해 왔습니다.<br>
> 현재 **홍익대학교 컴퓨터공학과 3학년 재학 중**이며 웹 개발, 웹 보안, 네트워크, 서버, 기획 등 다양한 직무로 프로젝트를 진행하며 견문을 넓히는 중입니다.
