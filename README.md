## 👋 About Me

**서비스의 방향을 정하는 것부터 직접 구현하고 출시·운영하는 과정까지 경험하고 있습니다.**

홍익대학교 컴퓨터공학과에 재학 중이며 웹 개발을 시작으로 **서버 · 네트워크 · 보안 · 프론트엔드 · 서비스 기획**까지 다양한 영역의 프로젝트를 진행했습니다.
